# PAC User Rules

个人维护的 PAC 代理匹配规则。

规则地址：

```text
https://raw.githubusercontent.com/wyfang/pac-user-rules/master/user-rule.txt
```

将该地址填入支持远程 PAC 用户规则的代理客户端。规则会影响域名的代理与直连路径，更新前应先检查差异，并按所用客户端的格式要求验证。

这是个人规则集，不保证适用于其他网络环境。
